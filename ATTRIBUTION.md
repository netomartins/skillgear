# Attribution and Credits

SkillGear is an open-source tool and catalog indexer designed to make AI agent skills discoverable and easily installable across development environments.

SkillGear does **not** host or redistribute proprietary skill packages. Instead, its catalog provides metadata and directs downloads from original open-source community repositories:

1. **VoltAgent / awesome-agent-skills**
   - Repository: [VoltAgent/awesome-agent-skills](https://github.com/VoltAgent/awesome-agent-skills)
   - Primary source for community skills, best-practice guides, and agent capabilities.

2. **Anthropic Skills**
   - Repository: [anthropics/skills](https://github.com/anthropics/skills)
   - Core skills including `skill-creator` and `frontend-design`.

3. **Vercel Labs**
   - Repository: [vercel-labs/agent-browser](https://github.com/vercel-labs/agent-browser) and [vercel-labs/skills](https://github.com/vercel-labs/skills)
   - Browser automation and agent tools.

4. **Obra Superpowers**
   - Repository: [obra/superpowers](https://github.com/obra/superpowers)
   - Test-driven development, code review, and workflow skills.

All skills downloaded through SkillGear remain the intellectual property of their respective authors and are subject to their respective open-source licenses.
